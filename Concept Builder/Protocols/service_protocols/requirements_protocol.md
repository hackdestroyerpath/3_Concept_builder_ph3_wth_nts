# Requirements protocol

Parent: [Protocol catalog](../catalog.md)
Status: `available`

## Purpose

Build and approve requirements for an issue before solution or output work starts.

## Steps

1. Read issue reason and QA trace.
2. Write requirements as stable IDs.
3. Separate in-scope and out-of-scope items.
4. Ask for approval when requirements affect output.
5. Reopen requirements if later input changes scope.

## Output

Approved or reopened requirements for the active issue.
