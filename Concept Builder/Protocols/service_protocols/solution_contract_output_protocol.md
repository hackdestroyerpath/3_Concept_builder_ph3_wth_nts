# Solution contract output protocol

Parent: [Protocol catalog](../catalog.md)
Status: `available`

## Purpose

Create solution, contract and output flow for an issue.

## Steps

1. Read approved requirements.
2. Draft solution with plan inside the same document.
3. Draft contract with acceptance checks.
4. Execute only after approval.
5. Save output report, changed files and coverage notes.
6. Validate before closure.

## Output

A checked output package for the active issue.
