# Question answer protocol

Parent: [Protocol catalog](../catalog.md)
Status: `available`

## Purpose

Collect only materially important questions and answers for an issue.

## Steps

1. Identify unknowns that can change requirements, solution or contract.
2. Ask concise questions.
3. Record answers in the issue scope or registry notes.
4. If the answer changes scope, reopen the relevant phase.
5. If no question is needed, record skip reason.

## Output

A QA trace or a clear skip marker.
