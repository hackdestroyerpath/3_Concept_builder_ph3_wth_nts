# Existing issue protocol

Parent: [Protocol catalog](../catalog.md)
Status: `available`

## Purpose

Open an existing issue, build a focus packet, check blockers and select the next phase protocol.

## Steps

1. Read [../../Issues/issue_registry.md](../../Issues/issue_registry.md).
2. Find issue status, phase and dependencies.
3. Check [../../Issues/dependency_graph.jsonl](../../Issues/dependency_graph.jsonl).
4. Select next protocol from [../catalog.md](../catalog.md).
5. Persist any state change.
